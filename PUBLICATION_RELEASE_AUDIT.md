# Publication release audit

Checked on **23 October 2026**. All **179 publication records** were audited.

Verified releases or project resources were found for **83 papers**. Added **167 release links** to the publication metadata.

## Method and limits

Checked local paper PDFs and public paper/proceedings pages where available, then matched repositories, project pages, model cards and datasets to the paper. Followed author release links to find additional artifacts. Used targeted title searches when a paper did not identify a clear release. Hugging Face models were checked for weight files; large directly hosted artifacts were checked with HTTP HEAD requests. Models and datasets were not downloaded.

“No verified release found” means none could be confirmed from these sources on this date; it does not establish that no release exists. Dependencies, unrelated benchmarks and third-party implementations are not listed as releases by the paper’s authors. Historical links that could not be verified remain in existing publication records and are identified below. A project link can contain tutorial or competition resources.

The machine-readable audit, including checked source URLs and search queries, is in [_data/publication_release_audit.yml](_data/publication_release_audit.yml).
